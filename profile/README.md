# Glintcast

Calm themes, cleaner layouts, and better player controls for Twitch on Chromium browsers.

- **Docs & Install:** https://glintcast.mintlify.app
- **Direct Releases:** https://github.com/Glintcast/glintcast/releases
- **Issues & Feedback:** https://github.com/Glintcast/glintcast/issues
- **Privacy Policy:** https://glintcast.mintlify.app/privacy
